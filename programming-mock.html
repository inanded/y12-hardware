Question 2: ClipStar [5 marks]

Skill: describe an array algorithm in steps

The video app ClipStar stores the number of views of each video in a 1D array Views of type INTEGER. The array contains 300 elements. Each element has a different value.

An algorithm is needed to find the largest number of views and output it.

Describe the steps that the algorithm should perform. [5]

Write numbered steps in English. You do not need to write pseudocode.

There is one mark for each clear step, up to 5. A strong answer covers all of these, in order:
  • a variable that will hold the largest value (and its data type);
  • what that variable starts as (where should the starting value come from?);
  • a loop, and exactly how many times it repeats;
  • how the loop counter is used;
  • the comparison made each time round;
  • what happens when the comparison is true;
  • what happens after the loop ends.
Answers lose marks for: inputting the 300 values (they are already in the array), starting the largest value at 0, saying "loop through the array" without saying how many times, and comparing an element with the next element instead of with the largest so far.
Around the skill: extra practice (not part of the 38 marks)

1. Set Max to 0
2. Input the 300 values

2. The values are already in the array, so there is nothing to input.

Question 3: The Discard Pile [7 marks]

Skill: stack in a 1D array · Push()

In a card game, players put cards face up on a discard pile. Only the top card can be seen or taken. The pile is a stack that can hold up to 108 cards.

The stack is implemented using a 1D array and two integer variables:

DECLARE Pile : ARRAY[1:108] OF STRING
  • Global variable NextFree points to the next free location in the array. Its value is an array index.
  • Global variable CardsOnPile is the number of cards currently on the pile.
  • The stack grows upwards from array element 1.

(a) Give the initial values that should be assigned to the two variables. [1]

Both values are needed for the mark. Read the definition again: NextFree points to the next free location, not the top card. When the pile is empty, which element will the first card go into?

(b) The pile starts empty. These operations happen in order:

Only "R7" is now on the pile, but Pile[2] and Pile[3] still hold "G2" and "G9".

Two marks means two separate points. Point 1: can an element at NextFree or above ever be popped or read while it is in that position? Point 2: what happens to the old value in that element when the next card is pushed?

Write pseudocode for Push(). The header is given. [4]

Marks are given for: (1) the procedure heading and ENDPROCEDURE; (2) declaring the input variable and both counts as local INTEGERs; (3) a conditional loop that ends on 0; (4) an INPUT inside the loop; (5) checking for multiples of 3 and of 5 inside the loop; (6) adding 1 to the right count, with both counts set to 0 before the loop; (7) outputting both counts with a message after the loop. A. One line, one lost mark. Why does OUTPUT "Threes: " & ThreeCount lose the mark when ThreeCount is an INTEGER? Give two ways to fix it.
& only joins strings (or a CHAR with a STRING). Fix 1: use a comma, OUTPUT "Threes: ", ThreeCount. Fix 2: convert first, OUTPUT "Threes: " & NUM_TO_STR(ThreeCount). pseudocode.pro lets the wrong version run, so you will not spot this by testing.
B. Same job, REPEAT...UNTIL. Rewrite FizzBuzzCount() using REPEAT...UNTIL instead of WHILE. How do you stop the final 0 being counted? (Hint: 0 MOD 3 = 0.) 
PROCEDURE FizzBuzzCount()
    DECLARE ThisNum, ThreeCount, FiveCount : INTEGER
    ThreeCount ← 0
    FiveCount ← 0
    REPEAT
        INPUT ThisNum
        IF ThisNum <> 0 THEN
            IF ThisNum MOD 3 = 0 THEN
                ThreeCount ← ThreeCount + 1
            ENDIF
            IF ThisNum MOD 5 = 0 THEN
                FiveCount ← FiveCount + 1
            ENDIF
        ENDIF
    UNTIL ThisNum = 0
    OUTPUT "Multiples of 3: ", ThreeCount, "   Multiples of 5: ", FiveCount
ENDPROCEDURE
Without the IF ThisNum <> 0, the 0 counts as a multiple of 3 and of 5, so both counts are 1 too high.
